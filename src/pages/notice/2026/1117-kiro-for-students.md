---
title: 学生向け「Kiro for Students」プログラムによるKiroの無償提供について
---

東京大学が「Kiro for Students」プログラムの対象校となりました．本学に在籍する学生は，Kiroの月1,000クレジットを最大12か月間，無償で利用できます（通常は年間240米ドル相当）．

Kiroは，ソフトウェア開発に用いられるAIエージェント型の開発ツールです．授業の課題，ハッカソン，スタートアップのMVPなど，作りたいものを伝えると，Kiroが仕様書（spec）と動作するアプリケーションを作成します．

## 対象者

本学に在籍する学生のみが対象です．教職員は対象外です．次の4つの条件をすべて満たす必要があります．

- 18歳以上であること
- 東京大学に現在在籍していること
- 東京大学のメールアドレスでKiroアカウントを作成していること
- 求められたときに在籍を証明できること

特典は1人1回のみです（12か月の期間終了後に再度申し込むことはできません）．また，特典を他者に譲渡すること，再発行を受けることはできません．

利用規約は[Kiro for Students Terms and Conditions](https://kiro.dev/students/terms-2026/)（英語）を確認してください．

## 特典内容

- 月1,000クレジットを最大12か月間，無償で利用できます．
- 有料プランで提供されるモデルも利用できます．IDE / CLI / Web / Crewで利用できます．
- クレジットカードの登録は不要です．
- クレジットは翌月に繰り越せず，追加購入もできません．
- 12か月経過後は，自動的に無料プランへ移行します．

### 授業・研究での利用

**授業においては，生成AIの利用の可否について，授業の特性に応じて担当教員が判断する**ことになっています．所属学科や専攻および各授業の担当教員の**指示に従い，認められていない場合には利用しない**でください．課題の提出時にAIの利用状況の記載を求められる場合は，その指示に従ってください．

論文誌・学会への投稿についても，生成AIの利用が禁止されている場合や，利用の開示などの条件が付けられている場合があるため，よく確認してください．

### 生成物に対する責任

Kiroが生成したコードや文書には，誤りや意図と異なる動作，脆弱性が含まれることがあります．また，既存のコードと類似したものが生成され，ライセンスや著作権上の問題が生じる可能性もあります．**生成物に対する責任は利用者が負います**．生成されたコードは内容を理解・確認したうえで利用してください．

### 入力する情報の取り扱い

Kiroは東京大学が組織として契約しているサービスではなく，各自がAWSの利用規約に同意して利用するサービスです．Kiroに入力した内容は，AIモデルを実行するAWSのクラウドに送信されます．

**初期設定のままでは，入力した内容（質問・コードなど）がAWSのサービス改善に利用される可能性があります．** 利用されたくない場合は，利用開始後に，次の手順で設定をオフにしてください．

1. KiroのSettingsを開きます．
2. 「User」タブ →「Application」→「Telemetry and Content」を開きます．
3. 次の2つのチェックを外します．
   - Usage Analytics And Performance Metrics
   - Content Collection for Service Improvement

設定をオフにした場合でも，入力した内容がAWSへ送信されること自体は変わりません．取り扱いに注意を要する情報（試験やレポートの問題，研究室・共同研究先などから提供された非公開のコードやデータ，発表・公開前の研究内容，個人情報，その他関係者以外が知りえない情報）は入力しないでください．判断に迷う場合は，その情報の責任者（研究室の指導教員や共同研究先など）に確認してください．

## 利用開始の手順

学生認証には，**[ECCSクラウドメール](/google/)のメールアドレス（`@g.ecc.u-tokyo.ac.jp`）** を利用してください．

1. Kiro（IDE / CLI / Web / Crew）にサインアップ，またはサインインします．
2. Settingsを開き，「Students」で東京大学（The University of Tokyo）を選択して「verify」を押します．
3. SheerIDの画面で，氏名・生年月日・大学のメールアドレス（`@g.ecc.u-tokyo.ac.jp`）を入力します．追加の書類の提出を求められる場合があります．
4. 認証が完了すると，プラン名が「Kiro Students」に変わり，すぐに利用できます．

学生認証は1回のみです．入力内容に誤りがないよう確認してください．申し込みページおよび手順の詳細は，Kiroの公式ページを参照してください．

- [Kiro for Students](https://kiro.dev/students/)（英語）
- [手順の詳細](https://kiro.dev/students/#instructions)（英語）
