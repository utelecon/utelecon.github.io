## Overview

ChromeOS devices provide a variety of accessibility features. By using these features, you can customize how content is displayed on the screen and make use of tools such as text-to-speech and captions. This page provides an overview of the accessibility features available on ChromeOS devices.

For more details and information about accessibility features provided by individual applications, please refer to [Google Accessibility Help > Accessibility on Chromebooks](https://support.google.com/accessibility?&hl=en#topic=9116829) (the light blue section near the bottom of the page contains information related to Chromebooks), as well as the resources introduced below.

## Customize Content Display

### Change Display Size

You can adjust the display size in a variety of ways, including zooming in or out on the entire screen, changing the size of specific content, or magnifying part of the screen using the Magnifier feature. For more information, please refer to the following resources:

- [Zoom in or magnify your Chromebook screen](https://support.google.com/chromebook/answer/6320705?hl=en&)
- [Change text, image & video sizes (zoom)](https://support.google.com/accessibility/answer/96810?hl=en&co=GENIE.Platform%3DDesktop&)

### Customize Text and Cursor Display

You can customize how text is displayed on websites, including the text size and font, and modify cursor display settings. For more information, please refer to the following resources:

- [Turn on Chromebook accessibility features](https://support.google.com/chromebook/answer/177893?hl=en&)
- [Making Your Chromebook Easier to See (English, YouTube video)](https://www.youtube.com/watch?v=v-NfA4pHsUc&t=12s)

### Adjust Colors and Brightness (Color Correction, Color Inversion, and More)

For information on how to configure color correction and color inversion settings, please refer to: "[Turn on Chromebook accessibility features](https://support.google.com/chromebook/answer/177893?hl=en&ref_topic=9016892&)".

Please note that brightness can also be adjusted through the [display settings](../hardware/#display).

## Use a Screen Reader

For information on using the built-in screen reader features available on ChromeOS, please refer to the following resources:

- [Use the built-in screen reader on your Chromebook](https://support.google.com/chromebook/answer/7031755?hl=en&)
- [Change the language or voice used for text-to-speech](https://support.google.com/chromebook/answer/11221616?hl=en&)

You can also use a screen reader to read PDF files containing handwritten text or images by combining it with Optical Character Recognition (OCR) functionality. For details, please refer to: "[Review, edit, and sign PDFs – Chromebook Help](https://support.google.com/chromebook/answer/12453461?hl=en&#zippy=%2Caccess-read-pdfs-with-optical-character-recognition-ocr)".

In addition, you can configure the Magnifier feature to follow the text currently being read aloud. For setup instructions, please refer to: "[Zoom in or magnify your Chromebook screen](https://support.google.com/chromebook/answer/6320705?hl=en&)".

## Use Captions

Chrome provides a feature that automatically generates and displays real-time captions for audio and video played in the Chrome browser. For more information, please refer to: "[Use captions on your Chromebook](https://support.google.com/accessibility/answer/10616170?hl=en&)".

## Use Caret Browsing

Caret Browsing allows you to navigate web pages and select text using the keyboard instead of a mouse.
For more information, please refer to: "[Use a text cursor to navigate & select text](https://support.google.com/accessibility/answer/10129654?hl=en&)".
